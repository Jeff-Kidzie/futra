## 2. Layout & Composition

### Page Layouts

All authenticated pages share a common shell: fixed sidebar (left, 240px desktop / overlay drawer mobile) + scrollable main content area.

```
┌──────────┬─────────────────────────────────────────┐
│          │  Header: [Page Title]    [Conn🔴] [User]│
│ Sidebar  │─────────────────────────────────────────│
│ 240px    │                                         │
│          │  Main Content Area                      │
│  • Home  │  (scrollable)                           │
│  • Trades│                                         │
│  • AI    │                                         │
│  • Charts│                                         │
│  • Alerts│                                         │
│  • Settings                                       │
│          │                                         │
└──────────┴─────────────────────────────────────────┘
```

### Route Layouts

| Route | Layout | Key Elements |
|-------|--------|-------------|
| `/login` | Centered card (400px max-w), no sidebar | Logo, username input, password input, Sign In button, error message area |
| `/` (Home) | Sidebar + main | AccountSummary (4 cards grid), PositionsTable, recent AlertFeed (last 5) |
| `/trades` | Sidebar + main | Filter bar (symbol, direction, date range), TradeHistoryTable, pagination, Export CSV |
| `/decisions` | Sidebar + main | Filter bar (symbol), DecisionLogTable with expandable rows, pagination |
| `/performance` | Sidebar + main | Time range selector (7d/30d/90d/all), EquityChart (full width), DrawdownChart (full width), metrics row (Sharpe, Sortino, Win Rate, Profit Factor) |
| `/alerts` | Sidebar + main | Filter tabs (All/Unacknowledged/Critical), AlertFeed (full list), Acknowledge All button |
| `/settings` | Sidebar + main | Notification preferences, strategy config read-only view, Log Out button |

### Responsive Breakpoints

| Breakpoint | Width | Layout Changes |
|------------|-------|---------------|
| Mobile | < 768px | Sidebar collapses to hamburger-triggered Sheet overlay. Cards stack vertically. Tables become card-list views (each row rendered as a card). Charts half-height. |
| Tablet | 768px – 1024px | Sidebar as narrow icon rail (56px) with tooltips. Cards 2-column grid. Tables full width with horizontal scroll. |
| Desktop | ≥ 1024px | Full sidebar (240px). Cards 4-column grid. Tables with all columns visible. Charts full width. |

### Grid System

- Card grids: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4`
- Content max-width: `max-w-7xl mx-auto` on main content
- Sidebar: fixed `w-60` (240px), main content offsets with `ml-60` on desktop

## 3. Typography & Hierarchy

### Font Family

| Element | Font |
|---------|------|
| Body, headings, UI | Inter (system sans-serif fallback) |
| Financial numbers | Inter with `font-variant-numeric: tabular-nums` (`.font-tabular` utility) |

### Font Sizes & Weights

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display (large metric) | 28px (text-3xl) | 600 (semibold) | 1.2 | Large P&L values, balance, equity on cards |
| Heading (page title) | 20px (text-xl) | 600 (semibold) | 1.2 | Page titles, card titles |
| Body | 14px (text-sm) | 400 (normal) | 1.5 | Table rows, paragraph text, descriptions |
| Body Emphasis | 14px (text-sm) | 600 (semibold) | 1.4 | Table headers, section labels, card sub-labels |
| Label / Caption | 12px (text-xs) | 600 (semibold) | 1.2 | Form labels, badge text, timestamp, helper text |
| Monospace data | 14px (text-sm) | 400 (normal) | 1.5 | Price columns, P&L values, position sizes (tabular-nums) |

### Number Formatting

| Data Type | Format | Example |
|-----------|--------|---------|
| Price | 5 decimal places (forex) / 2 decimals (indices) | `1.08500`, `4,520.50` |
| P&L (currency) | 2 decimal places, color-coded, signed | `+$125.50`, `-$42.30` |
| P&L (pips) | 1 decimal place | `+15.0`, `-8.5` |
| Percentage | 1 decimal place, signed | `+2.3%`, `-5.1%` |
| Margin / Free Margin | 2 decimal places | `$1,200.00` |
| Lot size | 2 decimal places | `0.10` |
| Duration | Human-readable | `2h 15m`, `3d 4h` |
| Date/time | ISO 8601 with seconds | `2026-05-26 14:30:00` |

### Color-Coded Values

| Condition | Color | Hex | Tailwind |
|-----------|-------|-----|----------|
| Profit / Win | Green | `#00E676` | `text-green-400` |
| Loss | Red | `#FF5252` | `text-red-400` |
| Neutral / Unchanged | Gray | `#9E9E9E` | `text-gray-400` |
| NaN / undefined | Gray (italic) | `#757575` | `text-gray-500 italic` |

### Information Hierarchy

Each page follows: **Title → Key Metrics → Detail Data → Actions**

1. **Title** (page heading, 20px/600): What page is this
2. **Key Metrics** (cards, 28px/600): The numbers that matter most
3. **Detail Data** (tables, 14px/400): Drill-down information
4. **Actions** (buttons, 14px/600): What the user can do (Export CSV, Acknowledge)

## 6. Component States & Interactions

### Loading States

| State | Visual | Where |
|-------|--------|-------|
| Initial page load | Skeleton screens (shadcn Skeleton) matching card/table layout | All authenticated pages |
| AccountSummary loading | 4 skeleton rectangles (200×120px) with shimmer | `/` |
| Table loading | 8 skeleton rows with shimmer | `/trades`, `/decisions` |
| Chart loading | Spinner centered in chart container | `/performance` |
| Login submitting | Button shows Spinner + "Signing in..." text, disabled | `/login` |
| WebSocket connecting | ConnectionStatus dot pulses amber, tooltip "Connecting..." | All pages (via Nav) |
| CSV export processing | Button shows Spinner + "Exporting..." text, disabled | `/trades` |

**Skeleton pattern:** `bg-muted animate-pulse rounded-md` matching the target component's dimensions.

### Empty States

| Empty State | Icon (Lucide) | Heading | Body |
|-------------|--------------|---------|------|
| No positions | `CircleOff` (circle-off) | No Active Positions | Trading has not started yet. Positions will appear here once the EA opens trades. |
| No trade history | `Receipt` (receipt) | No Trade History | Completed trades will appear here with entry/exit prices, profit, and duration. |
| No AI decisions | `BrainCircuit` (brain-circuit) | No AI Decisions Yet | AI decision logs will appear here once the engine analyzes market conditions and adjusts parameters. |
| Insufficient chart data | `LineChart` (line-chart) | Not Enough Data | At least 2 days of trading history are needed to display the equity curve. |
| No alerts | `BellOff` (bell-off) | All Clear | No active alerts. You'll be notified here when critical events occur. |
| No search results | `SearchX` (search-x) | No Results Found | Try adjusting your filters or date range. |

**Empty state layout:** Centered in content area, icon 48px in muted-foreground, heading 16px/600, body 14px/400 in muted-foreground, max-width 320px.

### Error States

| Error State | Icon | Heading | Body + Action |
|-------------|------|---------|---------------|
| MT5 disconnected | `PlugZap` (plug-zap) | MT5 Connection Lost | The dashboard cannot retrieve live data. Check that MetaTrader 5 is running and the EA is active. Retrying automatically... |
| Auth expired | `KeyRound` (key-round) | Session Expired | Your session has expired. **Sign In** to continue. [Sign In button → /login] |
| API failure | `AlertTriangle` (alert-triangle) | Unable to Load Data | Something went wrong while fetching dashboard data. **Retry** [Retry button] |
| WebSocket disconnected | `WifiOff` (wifi-off) | Live Updates Paused | WebSocket connection lost. Historical data is still available. Reconnecting... (Retry #N) |

**Error state layout:** Centered in content area, icon 48px in destructive color, heading 16px/600, body 14px/400, CTA button below.

### Real-Time Update Transitions

| Update Type | Animation | Duration | Easing |
|-------------|-----------|----------|--------|
| P&L value change | Color flash: background pulses green/red at 10% opacity then fades to transparent | 800ms | `ease-out` |
| New position row | Row slides in from top with fade | 300ms | `ease-out` |
| Position closed | Row fades out with slight scale-down | 400ms | `ease-in` |
| Account value change | Smooth CSS transition on the number (count-up effect) | 600ms | `ease-out` |
| Alert appears | Slide in from right (toast) or top (feed) | 300ms | `cubic-bezier(0.4, 0, 0.2, 1)` |

**Flash implementation:** When a P&L value changes, apply a transient CSS class:
```css
.flash-positive { animation: flash-green 800ms ease-out; }
.flash-negative { animation: flash-red 800ms ease-out; }

@keyframes flash-green {
  0% { background-color: rgba(0, 230, 118, 0.15); }
  100% { background-color: transparent; }
}

@keyframes flash-red {
  0% { background-color: rgba(255, 82, 82, 0.15); }
  100% { background-color: transparent; }
}
```

## 12. Implementation Notes

### CSS Variable Injection

All shadcn-svelte components inherit colors from CSS custom properties defined in `src/app.css`. The `:root` block defines the dark theme as the only theme (no light mode toggle needed). Color overrides for the Futra-specific palette are set via the CSS variables listed in Section 4.

### Font Loading

Inter is loaded via Google Fonts CDN in `src/app.html`:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600&display=swap" rel="stylesheet">
```

### Tailwind v4 Notes

Tailwind CSS v4 uses `@import "tailwindcss"` (not `@tailwind base/components/utilities`). The `@theme inline` block maps CSS variables to Tailwind utility classes. Theme customization in v4 is done via CSS, not `tailwind.config.js`.

### Oklch Color Format

All colors use the `oklch()` format for perceptually uniform lightness, which ensures consistent contrast ratios across the palette. The shadcn-svelte nova style and Tailwind v4 natively support oklch.
